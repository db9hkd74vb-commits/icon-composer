# 🎨 アイコン合成ツール (Icon Overlay Tool)

ブラウザ上でアイコン画像とフレーム画像を重ね合わせ、位置やサイズの調整をして保存できる軽量なWebアプリケーションです。サーバー不要で、HTMLファイルをブラウザで開くだけで動作します。

---

## ✨ 主な機能

* **画像の合成処理**
  * 背景（メインアイコン）と前面（フレーム画像）の重ね合わせ
  * ブラウザ上でリアルタイムプレビュー描画（HTML5 Canvas利用）
* **微調整コントロール**
  * **位置調整**: X軸・Y軸のスライド移動
  * **拡大・縮小**: 10% 〜 250% までの拡大率変更
  * **回転**: 0度 〜 360度の角度調整
  * **透明度**: アイコンの不透明度（0% 〜 100%）調整
  * **ワンタップリセット**: 調整値を初期状態に戻すボタン
* **レスポンシブ & モバイル対応**
  * PC・スマートフォン双方に最適化されたレイアウト
  * モバイルブラウザでの長押し保存（`image`タグ出力）および Web Share API による直接共有に対応

---

## 🛠️ 技術構成

* **HTML5**: マークアップ、ファイル入力処理
* **CSS3**: Flexbox, CSS Grid, レスポンシブデザイン、グラデーションスタイル
* **JavaScript (Vanilla JS)**: 
  * `FileReader API` によるローカル画像の読み込み
  * `Canvas API` による画像の拡大・回転・透過・合成処理
  * `requestAnimationFrame` によるスムーズな描画更新
  * `Web Share API` および Blob / URL オブジェクトを利用したダウンロード・共有処理

---

## 🚀 使い方

1. 本リポジトリの `index.html`（または該当のHTMLファイル）をダウンロードします。
2. ファイルを任意のWebブラウザ（Chrome, Safari, Edgeなど）で開きます。
3. **「① 背景（アイコン）」** と **「② 前面（フレーム）」** の画像を選択します。
4. スライダーを操作して、位置・サイズ・角度・透明度を好みに合わせて調整します。
5. **「📥 画像を保存 / 共有」** ボタンを押すか、プレビュー画像を長押し（スマホの場合）して画像を保存します。
