# 🎨 アイコン合成ツール

デバイスのファイルやカメラから取得したフレーム画像とアイコン画像を合成できるツールです。位置、サイズ、回転、不透明度を細かく調整できます。

## ✨ 機能

- 📤 **ファイルアップロード** - デバイスのフォトライブラリから画像を選択
- 📷 **カメラで撮影** - デバイスのカメラで直接撮影
- 🎯 **位置調整** - X/Y軸の位置をピクセル単位で調整
- 📏 **サイズ調整** - アイコンのサイズをパーセンテージで調整
- 🔄 **回転** - アイコンを0～360度回転
- 🎨 **不透明度** - アイコンの透明度を調整
- 👁️ **リアルタイムプレビュー** - 変更がすぐに反映
- 📥 **ダウンロード** - 合成結果をPNGで保存

## 🚀 使い方

### フレーム画像の取得
1. **🖼️ フレーム画像** パネルで下記のどちらかを選択：
   - 📁 **フォトライブラリ** - デバイスに保存されている画像を選択
   - 📷 **写真を撮影** - カメラで撮影

### アイコン画像の取得
2. **🎯 アイコン画像** パネルで下記のどちらかを選択：
   - 📁 **フォトライブラリ** - デバイスに保存されている画像を選択
   - 📷 **写真を撮影** - カメラで撮影

### 微調整と合成
3. **⚙️ 調整** パネルでスライダーを操作：
   - 位置、サイズ、回転、不透明度を微調整
4. **🔄 合成** ボタンで変更を反映（自動反映されます）
5. **📥 ダウンロード** で完成した画像を保存

## 🎛️ 調整パラメータ

| パラメータ | 範囲 | 説明 |
|----------|------|------|
| X 位置 | -200～200 px | 左右の位置をピクセル単位で調整 |
| Y 位置 | -200～200 px | 上下の位置をピクセル単位で調整 |
| サイズ | 20～200 % | アイコンのサイズを調整 |
| 回転 | 0～360° | アイコンの回転角度を調整 |
| 不透明度 | 0～100 % | アイコンの透明度を調整 |

## 🎨 描画順序

フレーム画像は最前面に配置されるため、アイコンをフレーム内に配置して合成することができます。

## 💻 技術仕様

- HTML5 Canvas を使用した画像合成
- ファイルAPI による ローカルファイル読み込み
- MediaDevices API によるカメラ撮影対応
- リアルタイムプレビュー
- PNGファイル出力

## 📱 対応環境

- デスクトップ（Chrome, Firefox, Safari, Edge）
- モバイルデバイス（iOS Safari, Android Chrome）
- カメラアクセス権が必要な場合あり
