# 🎨 アイコン合成ツール

URLで指定したフレーム画像とアイコン画像を合成できるツールです。位置、サイズ、回転、不透明度を細かく調整できます。

## ✨ 機能

- 🖼️ **URLから画像を読み込み** - フレームとアイコンのURLを指定するだけ
- 🎯 **位置調整** - X/Y軸の位置をピクセル単位で調整
- 📏 **サイズ調整** - アイコンのサイズをパーセンテージで調整
- 🔄 **回転** - アイコンを0～360度回転
- 🎨 **不透明度** - アイコンの透明度を調整
- 👁️ **リアルタイムプレビュー** - 変更がすぐに反映
- 📥 **ダウンロード** - 合成結果をPNGで保存

## 🚀 使い方

1. **フレーム画像URL** - 背景となるフレーム画像のURLを入力
2. **アイコン画像URL** - 合成するアイコン画像のURLを入力
3. **スライダーで調整** - 位置、サイズ、回転、不透明度を微調整
4. **合成ボタン** - 変更を反映
5. **ダウンロード** - 完成した画像を保存

## 📝 URLの指定方法

```
フレーム画像: https://example.com/frame.png
アイコン画像: https://example.com/icon.png
```

CORS対応のURLを使用してください。

## 🎛️ 調整パラメータ

| パラメータ | 範囲 | 説明 |
|----------|------|------|
| X 位置 | -200～200 px | 左右の位置をピクセル単位で調整 |
| Y 位置 | -200～200 px | 上下の位置をピクセル単位で調整 |
| サイズ | 20～200 % | アイコンのサイズを調整 |
| 回転 | 0～360° | アイコンの回転角度を調整 |
| 不透明度 | 0～100 % | アイコンの透明度を調整 |

## 💻 技術仕様

- HTML5 Canvas を使用した画像合成
- CORS対応の外部URLから画像を読み込み
- リアルタイムプレビュー
- PNGファイル出力
